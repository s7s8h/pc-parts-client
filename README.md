# PC Parts Hub – Front-End Client

PC Parts Hub is the front-end client for a full-stack PC parts management web application developed as an academic project for the Web-Based Systems course at King Faisal University.

The client provides an interactive interface for communicating with a Laravel REST API and managing PC parts data.

## Features

- User login and logout
- Token-based authentication
- Browse PC parts
- View detailed information for individual parts
- Filter parts by category
- Search parts by name, brand, or category
- Sort parts by price or rating
- Add new PC parts
- Edit existing PC parts
- Delete PC parts
- Protected management features for authenticated users
- Integration with a Laravel REST API

## Technologies

- HTML5
- CSS3
- JavaScript
- REST API
- GitHub Pages

## Backend

The application communicates with a separate backend REST API built with Laravel and MySQL.

Backend repository:
https://github.com/s7s8h/pc-parts-api

## Project Structure

- `index.html` – Main page
- `login.html` – User login
- `dashboard.html` – PC parts dashboard
- `add-part.html` – Add new PC parts
- `edit-part.html` – Edit existing PC parts
- `script.js` – Client-side logic and API communication
- `style.css` – Application styling
